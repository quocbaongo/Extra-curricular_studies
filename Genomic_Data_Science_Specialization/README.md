## About the Specialization

**Title:** [Genomic Data Science Specialization](https://www.coursera.org/specializations/genomic-data-science)  
**Platform:** Coursera  
**Provider:** Johns Hopkins University  
**Number of courses:** 6-course series

With genomics sparking a revolution in medical discoveries, it has become essential to better understand the genome and effectively leverage data from genomic datasets.

**Genomic Data Science** is the interdisciplinary field that applies **statistics**, **data science**, and **computational methods** to genomic information.

This Specialization teaches the concepts and tools needed to **understand**, **analyze**, and **interpret** data from **next-generation sequencing (NGS)** experiments.

### What You'll Learn

- How to use the **command line** for genomic data processing
- Core tools and software widely used in genomic data science
- Programming in **Python**, **R**, and **Bioconductor**
- Working with real genomic datasets
- Statistical analysis applied to genomics
- Common file formats and data processing pipelines in modern genomics
